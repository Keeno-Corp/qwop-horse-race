# Photo Finish Fiasco (QWOP horse race)

Riderless low-poly ragdoll horses, one key per leg. First nose across the line wins, most face-plants gets an award.

Play: https://qwop-horse-race.pages.dev

- Solo: Q W O P (front-left, front-right, back-left, back-right) vs 3 AI horses. R restarts.
- 2 players on one keyboard: press 2. Player 1 Q W E R, player 2 U I O P; Enter restarts.
- Space skips the slow-motion replay.

Built with [paprika3d](https://paprika3d.com). Static page: serve the repo root (`npx serve .`).
